# Логотип «КалорИИ»

Утверждённый знак: зелёное кольцо с четырёхлучевой искрой и светлой точкой вместо буквы «о». Основная надпись переведена в векторные контуры и не зависит от загрузки шрифтов. Версии для светлой и тёмной темы подключены в общем интерфейсе браузера и Telegram Mini App.

Палитра: зелёный `#1E8E5A`, светлый зелёный `#3DD08B`, тёмный фон `#0F1613`, светлая надпись `#E9F1EC`, тёмная надпись `#17231D`.

- `assets/branding/logo.svg` — надпись для светлого фона.
- `assets/branding/logo-dark.svg` — надпись для тёмного фона.
- `assets/branding/icon.svg` — исходник квадратной иконки; знак помещается в безопасную область maskable.
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — установка приложения и iOS.
- `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png` — упрощённый знак для вкладок браузера.
- `badge-96.png` — белый знак на прозрачном фоне для уведомлений Android.
- `assets/branding/telegram-avatar.png` — квадратный файл 1024×1024 для аватара бота; знак подходит для круглой обрезки.

Аватар бота и изображения профиля Mini App задаются отдельно в настройках Telegram; публикация веб-приложения не меняет их автоматически. Для `/setuserpic` в @BotFather используется `assets/branding/telegram-avatar.png`.

Исходные SVG и PNG воспроизводятся командой `node scripts/build-branding.cjs` с установленным пакетом `sharp` (можно передать его через `NODE_PATH`). В сборке favicon усилена толщина кольца, свечение убрано для читаемости при 16×16. Старые адреса PNG сохранены, в манифест добавлена версия для обновления кэша. Обновление уже установленной иконки зависит от браузера или Telegram.
